# Changelog

All notable changes to this project will be documented in this file.

## 2026-08-12

- Revised the GitHub comparison backend with strict request validation, safe API errors, nullable external metrics, parallel requests, and contract-based scoring.
- Connected comparison URLs to the live GitHub analysis endpoint while preserving the existing responsive comparison design.

## 2026-08-11

- Added persistent light-theme support with an accessible theme switcher.
- Added Netlify-ready Next.js build configuration with a pinned Node.js runtime.
- Added the RepoArena Phase 1 UI foundation, responsive repository comparison flow, preview analysis view, and interaction tests.
